Первый выпуск. Каталог на 133 методов, собран из первоисточника
(официальная спека `api.hh.ru/openapi/specification/public`).

- класс доступа read / write / destructive, запись требует подтверждения;
- кабинеты: ключи вне репозитория, права 600;
- `doctor` для проверки установки без секретов в выводе.
